The plugin disables ObjectHook and sets Aim to Game during a cutscene.


How to use:
Download & copy CutsceneDetectionPlugin.dll file to
```
%AppData%\UnrealVRMod\{GAME_EXE_NAME}\plugins
```
{GAME_EXE_NAME} is a name of an executable file of a game.
